# SafeZone

SafeZone is a smart personal safety mobile application designed to enhance personal safety, particularly for women, through real-time emergency alerts.

## Role

Flutter Developer

## Technologies

- Flutter
- Dart
- Firebase
- Supabase
- MapTiler
- Twilio SMS Gateway
- Kotlin

## Features

- Emergency alerts
- Location-based features
- Map integration
- Emergency SMS notifications
- Background functionality
